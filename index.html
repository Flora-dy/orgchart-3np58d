① 粘贴人员名单（在 Excel 里连表头一起全选 → Ctrl+C，在这里 Ctrl+V）

字段说明与排序规则（一般不用看，点开查阅）
列顺序和人员行顺序都可以打乱，系统会按表头识别并自动归组、排序。表头名称要和《人员信息填写模板.xlsx》一致： 中心 / 部门 / 分组 / 姓名 / 岗位 / 层级(中心·部门负责人·二传手·组长·骨干·培养) / 性别 / 学历 / 在职学历 / 毕业院校 / 所学专业 / 参加工作时间 / 来公司时间 / 职等职级 / 全日制 / 核心岗位 / B岗人员 / 培养方向 / 状态(管培生·试用·外包·产假) / 兼管分组 / 月薪 / 年薪
年限自动计算：新模板填写「参加工作时间」「来公司时间」，例如 2001、06、2001、6、2001-06 或 2001年6月。以「文件名／统计日期」为基准，按整月差÷12计算并保留1位小数；留空按当天。只填年份按当年7月估算。旧表的「工龄」「司龄」数字列仍可用。
岗位从高到低：副总 → 中心总监 → 中心副总监 → 部门总监 → 部门副总监 → 部门经理 → 部门副经理 → 主管 → 组长；层级填 B岗/B 岗会按二传手处理，填管培生会按培养处理。
可选列：显示岗位（图上用它替代岗位，正式岗位仍保留在表里）／架构角色（填「组头」指定本组负责人；未指定的组优先识别「层级=组长」，否则按组内现有排序取第一人）／不上图（填「是」的人保留在数据里，但不进图、不进 Word、不计入人数）／显示顺序（数字，控制组和人的先后，优先级最高）。
排序优先级：填了「显示顺序」→ 按它；勾选「按表格原顺序」→ 按 Excel 行序；都没有 → 按岗位高低自动排序。

③ 生成与导出

导出说明
PDF：点「打印」后在浏览器打印窗口选「另存为 PDF」，纸张选 A3 横向，即得矢量清晰版。
分析：需在名单里填了「月薪」或「年薪」才会输出薪酬部分；外包人员薪酬体系不同，不参与比较。
Word：下载的 .doc 用 Word/WPS 打开，可再「另存为 .docx」；需要公司页眉页脚时，把内容复制粘贴进《公司Word模板.docx》。
