# 组织架构图生成器

把 Excel 人员名单粘进去，一键生成组织架构图、Word 人员资料表、人才结构分析和人员盘点表。

**打开就能用 → https://flora-dy.github.io/orgchart-3np58d/**

## 特点

- **不用装任何软件**，浏览器打开就行；手机、公司电脑都能用
- **数据不出本机**：所有计算都在你的浏览器里完成，不上传任何服务器
- 支持最多 6 级组织，自动判定层级、院校层次（985/211/境外）、职能序列
- 导出 SVG / 高清 PNG / A3 横向 PDF / Word / 分析报告 / 盘点表
- 图上可直接拖动调整分组与人员顺序，支持撤销

## 怎么用

1. 下载 [人员信息填写模板.xlsx](人员信息填写模板.xlsx)，按「←填写须知」页填好
2. 连表头一起复制「人员名单」页的内容
3. 打开网站，粘贴到输入框，点「生成架构图」

只有 **组织1** 和 **姓名** 两列必填，其余留空不会报错。

详细填法见 [使用说明.md](使用说明.md)。

## 公司架构图（只画组织框架）

页面右上角「公司架构图 →」可切到 **公司架构图生成器**（[company.html](company.html)）：
不放人员，只画 董事长 → 总经理 → 各分管板块 → 中心 → 部门 的运营架构图，
配色与人员架构图一致（也可切换灰色简洁版）。

1. 下载 [公司架构填写模板.xlsx](公司架构填写模板.xlsx)，按「←填写须知」页填好
2. 连表头一起复制「人员名单」页的内容，粘贴进去，点「生成架构图」
